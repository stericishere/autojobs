# ATS playbook: SmartRecruiters (`jobs.smartrecruiters.com`, oneclick-ui)

No account. One page.

- Upload the resume first with the first "Choose File" button: the parser autofills the form.
  Then check every autofilled value. The parser often fills a school or secondary email
  instead of `candidate.email`: correct it.
- Comboboxes are listbox popups: open, read option labels from the snapshot / page, click
  the matching option.
- Screening questions are not in the public posting API; read them on the page.
- Some employers ask which AI tools you used to prepare the application. Answer truthfully
  (an AI agent prepared it), in the user's voice, and show the user before submitting.
